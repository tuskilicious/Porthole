PORTHOLE — logo package
========================

/primary/png      App icon, tangerine bg, ink mark — 16 to 1024px
/primary/ico       Windows multi-size .ico (16/24/32/48/64/128/256)
/marks/png         Mark alone, transparent bg, 4 colourways (ink / cream / tangerine / mint)
/wordmark/png      "porthole" lockup, 4 backgrounds incl. transparent
/alt-port-grid/png Alternate concept: port-grid icon, one tile lit
/svg               Vector sources for the primary mark (full + simplified-for-small-sizes) and the alt grid mark

Palette
  Ink        #131519
  Cream      #F4F1EA
  Tangerine  #FF7A45  (primary accent / "off" or neutral)
  Mint       #46E3A0  (reserve for "profile active" state only)

Typography
  Bricolage Grotesque 800 — wordmark
  Space Mono — port IDs, labels, counts

Use the "simple" mark variants (svg + the <=32px PNGs) below 32px — the full
mark's fill shapes (arrowhead, small square, dot) fuse together at tray size.
