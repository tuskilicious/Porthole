PORTHOLE — peripheral icon set (Lucide edition)
=================================================

20 device icons, sourced from Lucide (ISC license) and restroked to match
Porthole's line weight, then placed on Porthole's tile system.

WHICH IS WHICH
---------------
mouse         Lucide "mouse" — rounded body, scroll-wheel tick.
keyboard      Lucide "keyboard" — key-dot grid, base row.
headphones    Lucide "headphones" — headband arc into two cups.
microphone    Lucide "mic" — capsule head, stand, base.
webcam        Lucide "webcam" — lens rings on a stand.
camera        Lucide "camera" — body with shutter-release bump, lens circle.
gamepad       Lucide "gamepad-2" — full controller body, d-pad, four buttons.
joystick      Lucide "joystick" — flight-stick base, stick, ball top.
speaker       Lucide "speaker" — tower body, tweeter dot, woofer ring.
monitor       Lucide "monitor" — screen, stand, base.
printer       Lucide "printer" — body, paper-feed slot, output tray.
scanner       Lucide "scan" — four corner brackets (viewfinder/scan-area mark).
drive         Lucide "hard-drive" — angled top-loading case, activity dots.
flashdrive    Lucide "usb" — the trident-and-cable USB glyph (distinct from
              the app mark's power-ring trident — this one reads as a cable).
memorycard    Lucide "memory-stick" — RAM-stick pin row and latch notches.
phone         Lucide "smartphone" — vertical body, home-button dot.
tablet        Lucide "tablet" — wider body, home-button dot.
smartwatch    Lucide "watch" — case with lugs, crown tick, round face.
router        Lucide "router" — body, status dots, two wifi arcs.
cable         Lucide "cable" — two plug housings joined by a slack cable.

FOLDERS
-------
/png/tile-tangerine     icon on the Porthole tangerine tile — 32 to 512px
/png/tile-slate         icon on a dark-slate tile, for dark-theme lists — 32 to 512px
/png/transparent-ink    icon alone, transparent bg, ink line
/png/transparent-cream  icon alone, transparent bg, cream line

Naming: <device>-<size>.png, e.g. gamepad-128.png
